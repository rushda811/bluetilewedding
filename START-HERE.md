# Aurelle Vows wedding invitation

Full editable source, including floral images, sample gallery photos, and music.

## Run locally

Install Bun, open this folder in a terminal, then run:

```sh
bun install
bun run dev
```

Open the address printed in the terminal.

## Notes

- Guestbook wishes remain stored in each visitor’s browser; there is no shared guestbook service.
- Gallery photos are samples.
- Floral background, frame, and music use bundled local files in this export, so no Lovable asset connection is required.
- This is editable source, not a prebuilt static website.
